# RPG GameState Models

Готовая структура моделей для ASP.NET Core backend RPG с ИИ-мастером.

## Куда класть

Скопируй папку `Models` в свой проект `backend/Models`.

Пример файла состояния лежит тут:

`Data/game_state.example.json`

Его можно положить в свой проект как:

`backend/Data/game_state.json`

## Главная идея

Основной файл сохранения теперь не `player.json`, а `game_state.json`.

Он хранит:

- игрока;
- ресурсы;
- состояния;
- инвентарь;
- экипировку;
- бой;
- мир;
- локации;
- объекты мира;
- предметы внутри объектов;
- NPC;
- фракции;
- квесты;
- журнал истории.

## Важно

Экипировка хранит не названия предметов, а `id` предметов.

Например:

```json
"основнаярукаId": "item_longsword_001"
```

Так движок не перепутает два одинаковых меча.

## Пример для меча и колодца

Если игрок пишет: `я кидаю меч в колодец`, ИИ должен вернуть изменение:

```json
{
  "операция": "переместить_предмет",
  "предметId": "item_longsword_001",
  "из": "inventory",
  "в": "object:object_well_001",
  "причина": "Игрок бросил меч в колодец"
}
```

А `GameEngine.cs` уже должен:

1. Найти предмет в `игрок.инвентарь`.
2. Удалить его из инвентаря.
3. Если он был экипирован, очистить слот.
4. Добавить предмет в `мир.локации[...].объекты[...].предметы`.
5. Сохранить `game_state.json`.
